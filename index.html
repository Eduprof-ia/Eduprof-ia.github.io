Comment ça marche ?

Chaque document sauvegardé peut être partagé via un lien unique. Les élèves accèdent à eduflow.com/eleve/[CODE] (ou votre URL GitHub Pages) et voient le document en mode lecture — sans pouvoir le modifier.

Sauvegardez d'abord du contenu pour générer des liens de partage.
